# Aurora Lab · 폐곡선 에너지 흐름

작업일: 2026-10-14. 브랜치: `feat/glass-nebula-aurora`.

후속 [넓은 리본·중첩 흐름](./aurora-layered-streams-verification.md)에서 띠와 미스트를 확대하고 세 독립 채널/발생별 변동을 추가했습니다. 아래 단일 흐름의 긴 주기와 강한 공통 호흡은 이전 단계 기록이며 최신 동작은 후속 문서를 따릅니다.

## 구현

이번 단계는 기존 미커밋 `/aurora-lab` 구현을 이어서 주요 리본의 형상과 빛 애니메이션을 개선했습니다. 카메라 세 모드·패널·품질 선택·성운·별·유리·Bloom은 재사용하며 질문/캡슐/Q10/승인/API/기존 결과 화면에는 연결하지 않습니다.

### 닫힌 주요 리본

독립 리본 2~4개도 비정형 타원 중심선의 폐곡선으로 만들었습니다. 기존 `curtain` kind는 주요 리본의 역할 구분으로 유지하고 `closed: true`로 실제 닫힌 형태를 선택합니다. 반경의 2·3차 변화, 서로 다른 깊이·곡률·위상, 주기적인 폭 방향 꼬임과 부푼 횡단면으로 완벽한 기하학 고리의 인상을 줄입니다. 주요 리본은 `u=0,v`와 `u=1,v`가 같은 위치·접선을 가지며 열린 길이 끝단이 없습니다.

보조 Möbius-like 루프와 미스트는 기존 반 꼬임 연결(`u=0,v`와 `u=1,1-v`)을 유지합니다. 주요 리본의 보조 안개도 같은 폐곡선/pose/시드를 공유합니다. GPU 정점 변형은 주기적이고, 표면 노이즈는 원형 좌표를 사용합니다. 반 꼬임의 폭 대칭과 주요 리본의 닫힘을 별도 uniform으로 구분하여 주요 리본의 색과 코어를 보조 루프처럼 희미하게 만들지 않습니다. 양면·각도 보정·부드러운 경계·알파 감쇠는 재사용합니다.

기존 공통 장과 개별 공전의 공간 운동 gain은 **이전의 40%**로 줄였고, 정점 파동 gain도 줄였습니다. 개별 중심 위치·깊이·위상은 유지하므로 중앙 장 안에서 아주 완만하게 움직입니다. 카메라를 돌려 자체 움직임을 대신하지 않습니다. 새 폐곡선의 외곽을 포함하도록 카메라 안전 영역만 갱신했고 카메라 모드·속도·제약·복귀 정책은 유지합니다.

### 에너지 흐름과 잔광

리본별 고정 시드로 주기·시작 offset·이동 속도·길이·강조 위치·방향·gain을 결정합니다. 주요 리본은 양방향을 섞고, 본체와 그 안개는 같은 시드를 사용합니다. 프리셋/품질/모드/프레임 변경으로 시드를 다시 뽑지 않습니다. 시드 기반 패턴은 반복 가능하며 매 주기 새 무작위 패턴을 만드는 방식은 아닙니다.

| 항목 | 범위/정책 |
|---|---|
| 개별 주기 | 에너지 시간 22~31초 |
| 흐름 구간 | 8.5~12초, 완만한 공격/감쇠 |
| 잔광 | 흐름 길이의 125% 시점까지 점진적 감쇠 |
| 완전한 개별 휴지기 | 잔광 후 최소 6초 이상 |
| 흐름 속도 | 0.065~0.12회전/에너지 초 |
| 흐름 길이 파라미터 | 둘레의 0.14~0.26 |
| 방향/강조 위치 | 시드별 ±방향·원주상의 위치 |
| 공통 호흡 | 32초의 부드러운 장 리듬, 최소 호흡 0.12 |

위 초 단위는 **에너지 클록** 기준입니다. 기존 프리셋 `flow`를 `1.6 × flow / (0.5 + flow)`의 제한된 속도로 적분하므로 실제 벽시계 리듬은 프리셋마다 다릅니다. 공통 호흡 위에 독립 흐름을 얹어 일부 리본만 밝아지고 다시 안정 구간으로 돌아옵니다. 잔광은 별도 감쇠 곡선과 낮은 최소 호흡을 가져 공통 호흡이 줄어든 뒤에도 잠시 남습니다.

흐름은 실제 길이 UV `u`를 따라 이동하는 원주상 비대칭 Gaussian이며, 공간 연결부를 지나도 위치가 끊기지 않습니다. 앞부분을 충분히 넓히고 시작/끝에 smoothstep을 적용해 on/off 깜빡임을 피합니다. 코어·미세 필라멘트·안개의 밝기와 농도를 국소적인 흐름/잔광에 연동합니다. 휴지기에도 낮은 유색 코어와 안개 윤곽은 남습니다. 기존 팔레트/Bloom을 유지하고 순백색 광원을 추가하지 않습니다.

에너지 시간은 기존 공유 motion clock에 별도로 누적합니다. 카메라 조작/프리셋 변경으로 초기화되지 않고, 시스템/수동 움직임 감소 및 비활성 탭에서는 정지합니다. `flow` 변화는 보간한 값을 적분하므로 전체 경과 시간에 새 속도를 곱해서 위상이 튀지 않습니다. 렌더 프레임에서는 새 React 상태·시드·프로필 배열을 만들지 않고 GPU uniform과 기존 pose/ref를 갱신합니다.

## 품질·비용·보존

low/balanced/high의 기존 정점·미스트·입자·유리·DPR·Bloom 예산은 이번 단계에서 늘리거나 줄이지 않았습니다. 모바일이라는 이유로 품질을 강등하지 않으며 선택값을 그대로 유지합니다. 주요 리본과 보조 안개의 draw 수/저장소도 이전 단계와 같습니다. 에너지 Gaussian/호흡 계산으로 프래그먼트 연산은 추가되며 휴지기에는 국소 흐름 계산을 일찍 종료합니다. 실제 FPS가 유지된다고 보장하지 않습니다.

패널의 Independent는 독립적인 주요 폐곡선들, Hybrid는 주요 폐곡선 + 보조 반 꼬임 루프 1개, Loop Emphasis는 보조 2개입니다. 기존 옵션/라벨/리본 수/카메라 UI를 변경하지 않았습니다. 성운·별·유리 조각 분포와 전체 배경 미감도 보존했습니다.

### WebGL·화면

기존 로컬 `127.0.0.1:3000/aurora-lab`에서 Chromium 156 / ANGLE SwiftShader 소프트웨어 WebGL 2를 실행했습니다. 검증 브라우저는 외부 및 `/api/` 요청을 차단합니다. 프로젝트 의존성/호스트 패키지/폰트·환경변수 파일을 변경하지 않았습니다. 브라우저 실행 도구와 캡처는 `/tmp`에만 있습니다.

실제 GLSL 에너지 함수를 별도 1픽셀 WebGL 프로그램에서 160개 시드/시간/원주 위치 표본에 대해 실행하고 CPU 기준값과 비교했습니다. RGBA8 양자화 포함 최대 오차는 **0.001941**, WebGL 오류는 **0**입니다. 연결부/휴지기/흐름/잔광에 사용되는 실제 곡선이 CPU 검사와 같은지 확인한 것이며 GPU 성능 측정은 아닙니다.

실제 장면은 움직임 감소로 공간 위상을 고정한 뒤, 검증 스크립트의 GL uniform 계측만으로 에너지 위상 49.9(안정), 23/25(흐름 이동), 30(잔광)을 캡처했습니다. 제품에 시간 조절용 디버그 API를 넣지 않았습니다. 고정 형태 위로 유색 코어의 밝은 구간이 이동하고 다시 가라앉는 것을 직접 비교했습니다. 연속 동영상 전체 주기를 감상한 검증은 아닙니다.

같은 공간 시간 8.3, 에너지 위상 23에서 **low/balanced/high의 정면·측면·후면 9장**을 비교했습니다. 모든 단계에서 열린 끝단이 없고, 측면에는 전후 곡률·희미한 안개, 후면에는 연결된 루프와 순환하는 코어가 보입니다. 시선/자기 겹침에 따라 밝기와 가시 구간이 달라지며 모든 방향의 이미지가 같지는 않습니다. 각 품질에서 선택값과 진단 입자/유리/DPR 상한이 유지되었고 page/console/crash 목록은 비어 있으며 장면 WebGL 오류도 0입니다.

최초 품질 브라우저 검사에서는 renderer crash로 캡처가 중단됐습니다. 종료 원인을 확정하지 못했고, 다른 컴파일 검사가 없는 단독 재실행과 최종 품질/GLSL 검사는 통과했습니다. 이 환경의 실패와 재실행 결과를 장시간 안정성·GPU 메모리 누수 부재의 증거로 취급하지 않습니다.

## 남은 한계와 중단 범위

리본과 미스트는 얇은 곡면을 겹친 근사 표현이며 실제 볼륨 광산란은 아닙니다. 접선 각도에서 얇아지는 실루엣, 자기 겹침/투명 정렬, 미세한 분할 면은 남습니다. 닫힘은 길이 끝단을 제거하는 것이며 폭의 가장자리는 부드러운 알파 경계로 남습니다. GPU 부동소수점 연결부와 색감/순환 리듬의 미학적 만족도는 실기기에서 추가 비교해야 합니다.

실제 GPU의 FPS·메모리·발열·배터리·고밀도 DPR·장시간 반복 전환과 여러 완전한 에너지 주기의 연속 감상은 미검증입니다. 여기의 캡처는 800×600/DPR 1의 소프트웨어 렌더링입니다. 정면보다 측면의 휴지기 윤곽이 더 희미한 특성도 남습니다.

질문·캡슐·Q10 추천/문장 승인·분석/OpenAI API·기존 결과 화면은 수정하지 않았습니다. 커밋·푸시·배포·브랜치 전환, backup/master·리뷰 ZIP·환경변수 변경 없이 이 독립 실험 단계에서 종료합니다.
