# 자유 부유 캡슐 검증

검증일: 2026-10-12. Chromium 156.0.8078.4, 최종 검증은 CPU 렌더러를 사용했습니다.

## 구현

- 기존 그리드의 중앙을 시작 위치로 사용합니다. 약 0.9초의 안정 구간 이후 서서히 가속하며, 시작점으로 돌아가도록 끌어당기는 힘은 없습니다.
- 캡슐 ID별 위상·회전 방향·속도를 부여하고, 의미 그룹별 속도 성격을 유지합니다. 시간에 따라 진행 각도가 부드럽게 바뀝니다.
- 너비·높이를 측정한 캡슐 주변에 12px의 안전 간격을 둡니다. 접근 시 위치를 분리하고 접근 속도의 18%만 남겨 약하게 반발합니다. 고정한 캡슐에는 충돌 보정이 적용되지 않습니다.
- 경계 34px 전부터 안쪽으로 조향하고, 마지막 경계에서는 속도를 감쇠해 반전합니다.
- 매 프레임 React 상태를 갱신하지 않습니다. 몸체 상태는 ref에 보관하고 transform만 기록합니다. 레이아웃은 초기화·크기 변경 때만 측정합니다.
- 프레임 간격을 작은 계산 단계로 나눠 충돌을 처리합니다. 탭이 숨겨지거나 부유가 일시정지되면 프레임 루프를 멈춥니다.
- 동작 감소 설정에서는 속도를 65%로 줄입니다. 기존 부유 시작/멈춤 버튼도 유지합니다.

## 실제 브라우저 측정

초기 중심이 그리드 중앙과 일치했고 초기 450ms 동안 이동하지 않았습니다. 이후 35076ms 동안 349회 좌표를 측정했습니다.

시작점으로부터 최대 이동 거리: 167.81px. 겹침·영역 이탈·다른 그리드 셀에 의한 클릭 차단: 0건.

## 드래그 및 기존 기능

- 드래그 중 700ms 동안 선택한 캡슐의 좌표가 고정됨을 확인했습니다.
- 성공한 드롭 후 3초 동안 14.23px 이동해 흐름 복귀를 확인했습니다.
- 실패한 드롭 후 3초 동안 16.32px 이동해 재개를 확인했습니다.
- 움직이는 캡슐을 실제 마우스 좌표로 클릭해 선택 정확도를 확인했습니다.
- 중복 선택, 같은 단어 생성, 삭제, 질문 이동 후 선택·사용자 키워드 복원, 부유 멈춤을 확인했습니다.

## 정적 검사와 계산 테스트

- `npx tsc --noEmit`: 통과.
- `npm run lint`: 통과.
- 800×640, 350×650, 304×650 공간에서 각각 120초 계산 테스트: 겹침·경계 이탈 없음.
- 캡슐을 고정한 추가 계산 테스트와 약한 반발 시 속도 감쇠 테스트: 통과.
- 브라우저 런타임 오류: 0건.
- AI API, 결과 화면, 질문 데이터, 공통 레이아웃 및 의존성 파일의 해시가 수정 전과 동일합니다.

## 시각 표현과 한계

- 배경은 네이비에 라벤더·청록·옅은 분홍의 큰 빛과 느린 안개 띠, 미세한 입자 질감을 겹칩니다.
- 유리는 넓은 상단 반사광, 굽은 측면 굴절광, 하단 내부 그림자와 색 안개로 표현합니다. 움직이는 캡슐의 배경 블러는 제거해 합성 비용을 줄였습니다.
- 충돌은 실제 둥근 유리 형상의 접촉이 아니라 보수적인 사각 경계 근사입니다. 굴절 역시 CSS 시각 표현입니다.
- 전체 캡슐 쌍을 비교하므로 키워드가 매우 많아지면 CPU와 합성 레이어 메모리 비용이 증가합니다.
- 매우 긴 프레임 간격은 120ms로 제한해 순간 점프를 방지하므로 느린 렌더러에서는 부유가 늦어질 수 있습니다.
- 실제 iPhone/iPad Safari와 RTX 3050 Ti 하드웨어의 FPS는 측정하지 않았습니다. 실제 OpenAI 요청은 차단했습니다.
